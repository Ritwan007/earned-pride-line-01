# One Line of Earned Pride

Entry for the [make.fun competition "One Line of Earned Pride"](https://make.fun/competitions/u-mang-one-line-of-earned-pride-a0138557): one line, 1–240 characters, giving a quiet, earned moment of pride for someone in a scene.

## The line

> On the third night of the blackout, the boy who'd memorised the fuse box by torchlight brought the whole street back on.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

The program is deterministic: it writes the same 120-character line on every run, after validating it against the gate (single line, 1–240 characters, UTF-8, not only whitespace).
